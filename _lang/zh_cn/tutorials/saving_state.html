Saving State

Everything you have built so far is stateless: a variable is always recomputed from the current values of its inputs, so a network has no memory of what happened before. Sometimes you need exactly that memory, for example a lamp that stays on after a button was pressed. In this tutorial, we will use the Delayer to save state.

A Delayer remembers the previous values of the Variable Card in its top slot, and exposes them as a List. Start by crafting one, attach it to a network with a Redstone Reader that is targeting a Button, and insert the reader's Boolean Redstone Variable Card into the top slot. Set the Capacity to 1 in its gui, and write a new Variable Card using the bottom slots. This card refers to the Delayer's history.

The trick for saving state is a feedback loop: put a Variable Card in the Delayer whose value depends on the Delayer's own history. Each tick, the Delayer evaluates that card and stores the result, which becomes the previous value on the next tick. Let's use this to build a latch: a lamp that is switched on by one Button, and switched off by another.

Read the two Buttons with Redstone Readers as Boolean Redstone cards On and Off. Next, define Previous using the Get Or Default operator on the history card with index 0 and default False, so that it also works while the history is still empty. Now define State as On Or (Previous And Not Off), and place it in the Delayer's top slot. Place all referenced cards in a Variable Store. Finally, create a second State card in the same way, and insert it into a Redstone Writer that is targeting a Redstone Lamp. The lamp will now stay on after pressing On, until you press Off.

For the final part, we will make a toggle that flips on every press of a single Button. If we would simply invert Previous while the Button is pressed, the state would flip on every tick of the press. We therefore need to detect the exact tick in which the Button becomes pressed. Place a second Delayer with Capacity 2, insert a Redstone card of the Button, and write its history card. This history is exactly [False, True] in the tick after the Button was pressed.

Define Edge as this history card Equals a static List of the Booleans False and True. Now define State using the Choice operator: if Edge, then Not Previous, otherwise Previous. Place it in the top slot of the first Delayer, and insert a second copy into the Redstone Writer. Every press of the Button now toggles the lamp. Feedback loops like these can save any kind of value, not just Booleans, so you can now build counters, timers and much more.

Sneaky Entity Tracking

With the entity NBT reference variable from the previous step, open your NBT Extractor again, and place a blank Variable Card into the right slot. Expand the Pos list, which stores the entity's X, Y and Z coordinates as doubles. Left click entry #0 to select the X position and to write the extracted value.

Place a Display Panel on a Cable in the same network and insert the extracted X position Variable Card. The panel will display the entity's current X coordinate in real time. As long as Auto Refresh is enabled on the NBT Extractor, the value updates whenever the entity moves.

Introduction

Integrated Mekanism is an extension to Integrated Dynamics that adds deep integration with the Mekanism mod.

This mod allows you to read properties of chemical-related machines, apply operators over them, transfer chemicals over networks, access chemicals using the Storage Terminal, and perform autocrafting using chemicals.

Utilisation

Pour commencer, placez une Carte de variable de type NBT dans l'emplacement de gauche de l'Extracteur NBT. Le bloc lira la variable et affichera son contenu sous forme d'arbre repliable.

Faites un clic droit sur n'importe quelle balise composée ou entrée de liste dans l'arbre pour la développer ou la réduire. Continuez à descendre jusqu'à atteindre la valeur que vous souhaitez extraire.

Faites un clic gauche sur l'entrée cible pour sélectionner son chemin. Une fois un chemin sélectionné, placez une Carte de variable compatible dans l'emplacement de droite. L'extracteur écrira la valeur extraite dans cette carte selon le Mode de sortie actif.

Le Mode de sortie détermine comment la valeur de sortie est créée. En Mode référence, la variable de sortie conserve une référence en direct vers la valeur extraite et se met à jour à chaque changement de la variable NBT source. En Mode opérateur, le chemin d'extraction est encodé sous la forme d'un Opérateur réutilisable qui accepte n'importe quelle entrée NBT et renvoie la sous-valeur. En Mode valeur, la valeur actuelle est écrite dans la carte sous forme de constante fixe. En Mode chemin NBT, le chemin lui-même est stocké sous forme d'une chaîne CyclopsCore NBT Path.

Pour la plupart des cas d'usage, le Mode référence est le bon choix. Si vous souhaitez un instantané qui ne change pas, ou si vous comptez appliquer la même extraction à de nombreuses valeurs NBT différentes, envisagez respectivement le Mode valeur ou le Mode opérateur.

Le bouton Actualisation automatique de l'interface détermine si l'arbre NBT affiché se met à jour automatiquement lorsque la variable source est modifiée. Désactivez-le pour figer la vue dans son état actuel, ce qui est utile pour inspecter des données changeant rapidement.

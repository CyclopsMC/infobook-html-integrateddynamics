Introduction

Integrated NBT is an extension to Integrated Dynamics that adds tools for working with NBT (Named Binary Tag) data. It allows you to visually navigate, inspect, and extract deeply nested values from any NBT-typed variable on your Integrated Dynamics network.

Whether you need to pull a single integer out of a complex item tag, extract a string buried inside a nested compound, or encode a reusable extraction path for use in operators — Integrated NBT makes it straightforward, with no extra wiring required.

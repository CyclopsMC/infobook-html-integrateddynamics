Processo de Criação

Esta seção explicará como o processo de criação é tratado pelas Interfaces de Criação. Esta informação é essencial para tirar o máximo proveito deste mod e para depurar quaisquer problemas que você possa encontrar.

Quando um trabalho de fabricação é iniciado (por exemplo, com o Escritor de Fabricação), uma (ou mais) Interface(s) de Fabricação serão usadas se possuírem uma receita correspondente ao trabalho dado. Todos os ingredientes necessários para as receitas serão retirados da rede e mantidos dentro dos trabalhos de fabricação nas Interface(s) de Fabricação, para evitar que os ingredientes sejam usados em outro lugar antes que os trabalhos de fabricação sejam concluídos. A Interface de Fabricação é responsável por inserir todos os insumos da receita na máquina vinculada. Ela fará isso com base no conteúdo da rede de armazenamento, conforme fornecido pelas Interfaces do Integrated Tunnels.

Uma Interface de Fabricação, no entanto, não importará os resultados da fabricação da máquina vinculada. O jogador é responsável por garantir que os resultados da fabricação retornem para a rede. A Bancada de Trabalho é uma exceção a isso; apenas uma Interface de Fabricação é necessária para fabricar com ela. A Interface de Fabricação rastreará mudanças na rede de armazenamento e só marcará o trabalho de fabricação como concluído assim que as saídas esperadas estiverem presentes na rede de armazenamento. Isso pode ser alcançado colocando um Importador do Integrated Tunnels ativo na máquina, ou deixando a máquina enviar automaticamente a saída para a Interface de Fabricação. Tudo (itens, fluidos, energia) que for inserido na Interface de Fabricação será inserido na rede de armazenamento para o canal configurado.

QIO Interface

The QIO Interface links your network to a QIO frequency, without needing a cable to any QIO block. All items in the frequency become available to the network, so they can be accessed using the Storage Terminal, moved by Item Importers and Item Exporters, and used for autocrafting. Items inserted into the network can also end up in the frequency, depending on its priority.

Right-click the interface to select one of the frequencies you have access to, and to set its priority and channel. Alternatively, copy the frequency of a QIO block onto a Configuration Card by sneak-right-clicking that block, and right-click the interface with the card.

Each interface links to one frequency, so place multiple interfaces to link multiple frequencies. Items are only available while the QIO Drive Arrays of the frequency are loaded.
